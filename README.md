# OmniSales Analytics Dashboard

A responsive, single-page sales analytics dashboard built with vanilla HTML, CSS, and JavaScript.

## Features

- **Real-Time KPIs**: Total Revenue, Total Orders, Average Order Value (AOV), Items Sold, and Net Margin.
- **Quota & Goal Attainment**: Interactive sales target tracker with dynamic pacing indicators.
- **Interactive SVG Visualizations**:
  - Daily Revenue & Order Volume dynamics (area and line charts).
  - Category breakdown donut chart with segment hover tooltips.
  - Channel performance bars (Online Store, Retail Outlet, B2B Wholesale, Marketplace).
  - Top 5 Products Leaderboard.
- **Transactions Ledger**:
  - Live search across Customer, Item, and Order IDs.
  - Status and category filtering.
  - Multi-column sortable table with pagination.
  - Record, Edit, and Delete transactions modal.
- **Zero Backend / WebStorage Persistence**:
  - Local browser storage (`localStorage`) persistence.
  - Pre-seeded with realistic sample sales transactions.
  - Export to CSV.
  - Backup & restore via JSON.
  - One-click demo data reset.
  - Print-friendly Executive Report formatting.
- **Strict CSS Architecture**: Engineered without CSS variables or external UI frameworks.

## Quick Start

Open `index.html` in any modern web browser. No server, build steps, or external dependencies required.
